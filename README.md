# Doors OS V10.0™

Doors OS is a small web project that tries to make a desktop operating system inside a browser.

I made it using HTML, CSS and JavaScript.

## What can it do?

* Desktop interface
* Start menu
* Taskbar
* Draggable windows
* My Computer
* Virtual C:\ drive
* Calculator
* Doors Anti Virus
* Shutdown screen

## My Computer

My Computer shows a fake C:\ drive with folders like:

```text
C:\Doors
C:\Program Files
C:\Users
C:\Documents
```

These are only inside the website. They are not the real folders on the computer.

## Calculator

The calculator can do basic operations like addition, subtraction, multiplication and division.

It also has a dark/light theme.

## Doors Anti Virus

This is a fake antivirus made for the project.

It has a scan animation, file counter, threat results and scan completion message.

It does not actually scan the computer.
