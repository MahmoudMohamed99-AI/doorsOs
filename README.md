# 🖥️ Doors OS V10.0™

A web-based operating system simulation inspired by classic desktop operating systems.

**Doors OS V10.0™** is an interactive front-end project that recreates the look and feel of a simple desktop environment directly in the browser.

> Developed by **Ziniors Corporation™** since 2025.

## ✨ Features

* 🖥️ Desktop-style operating system interface
* 📁 **My Computer** with a simulated `C:\` drive
* 📂 Simulated folders:

  * `C:\Doors`
  * `C:\Program Files`
  * `C:\Users`
  * `C:\Documents`
* 🧮 Built-in calculator
* 🛡️ **Doors Anti Virus v1.0**

  * Simulated system scan
  * Animated scan progress
  * Files scanned counter
  * Threat detection simulation
  * Last scan timestamp
  * Real-time protection status
* 🪟 Draggable application windows
* 📌 Dynamic taskbar
* ☰ Start menu
* 🌙 Calculator dark/light theme
* 🔌 Simulated shutdown screen
* 💻 Terminal-style command system
* 📢 StartApp SDK integration

## 🧰 Technologies

This project is built using:

* **HTML5** — Structure and interface
* **CSS3** — Styling and desktop UI
* **JavaScript** — Interactivity and application logic
* **Font Awesome** — Icons
* **StartApp SDK** — Advertisement integration

## 🖱️ Simulated Applications

### My Computer

Provides a simulated file-system interface where users can navigate through the virtual `C:\` drive and its folders.

### Calculator

A basic calculator supporting:

* Addition
* Subtraction
* Multiplication
* Division
* Decimal numbers
* Delete
* Clear
* Theme switching

### Doors Anti Virus

A fictional antivirus interface featuring an animated simulated system scan.

The scan generates:

* Random file counts
* Random simulated threats
* Scan progress
* Scan completion notifications

**Note:** This is only a simulation and does not scan the user's actual computer.

### Terminal

The project also includes a terminal-style command system with commands such as:

```text
help
clear
about
date
echo [text]
color [color]
```

## 🎨 Design

Doors OS is designed to feel like a fictional retro operating system while combining classic desktop UI concepts with modern web technologies.

The interface includes draggable windows, a taskbar, a Start menu, application windows, and simulated system utilities.

## 🚀 Running the Project

No installation or build system is required.

1. Clone the repository:

```bash
git clone https://github.com/MahmoudMohamed99-AI/Doors-OS.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

That's it!

## ⚠️ Disclaimer

Doors OS V10.0™ is a **web-based simulation** and is not a real operating system.

The antivirus, file system, terminal, shutdown function, and other system components are simulated using JavaScript and do not interact with the underlying operating system
